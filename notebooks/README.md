# Early notebooks

This folder contains most of my early notebook-based work from when I was
still exploring the initial idea using Gemma.

At this stage, I hadn't yet settled on the final experiments or even the
behavioural taxonomy that I ended up using. I was mainly trying different
question pairs, transferring different amounts of conflicting reasoning, and
then manually looking at what Gemma did afterwards. The earliest notebooks
therefore contain interactive versions of the experiment where I could enter
the questions and traces myself and inspect the continuation directly.

As I started to understand the behaviour better, I gradually expanded these
notebooks into larger experiments. This included collecting source reasoning
traces, running the interventions at different trace depths, analysing the
first larger set of outputs, and experimenting with things such as answer-only
controls and internal model states.

There are several notebooks with similar names because I changed the
experiment quite a few times during this stage. Some versions fixed formatting
or runtime problems, while others added controls or changed the way I was
collecting the outputs. I've kept representative versions of the main
experiments here, while the smaller changes and earlier versions can still be
seen through the Git history.
